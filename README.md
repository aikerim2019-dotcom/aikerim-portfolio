# Айкерим Кусанова — кәсіби портфолио

## Нақты карточкаға құжат не фото қосу

Мысалы, «Білімі» карточкасының немесе 2026 жылғы ЖИ курсының ішінде орналасқан «Құжат қосу» немесе «Фото қосу» батырмасын басыңыз. Өз GitHub аккаунтыңызбен файлды таңдаңыз да, «Commit changes» арқылы сақтаңыз. Жариялау аяқталған соң материал сол карточканың ішінде пайда болады.

Әрбір курс, мақала, марапат, студент жетістігі, жеке мәлімет және тәжірибе карточкасының жеке файл қалтасы бар. «Қосу және басқару» тармағында файлдарын басқару сілтемесі орналасқан. Файл атауы оның көрсетілетін атауына айналады. PDF және фотолар сайт ішінде ашылады; Word және PowerPoint файлдары жүктеп алынады.

Түбірдегі documents.meta.json бұрыннан берілген PDF-терді тиісті карточкаларымен байланыстырады. Жаңа файлдар documents/items/<card-id>/files немесе photos ішінен автоматты оқылады. Жүктелген барлық құжат жалпы қорда да сақталады. items.config.json карточкалардың тұрақты атаулары мен бөлімдерін анықтайды.

Қолдау: PDF, DOC, DOCX, PPT, PPTX, JPG, PNG, WebP, GIF. Басты беттегі жеке фото карточкасына салынған бірінші фото негізгі портретті ауыстырады.

Build: node scripts/build.mjs
Жариялау: GitHub Actions / GitHub Pages. Келушілерге аккаунт қажет емес. Өзгертуге тек сайт иесінің құқығы бар.
