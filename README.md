# Айкерим Кусанова — кәсіби портфолио

## Сайттың ішіндегі басқару

Енді әр файлды қосу немесе жою үшін GitHub бетіне өту қажет емес. «Басқаруға кіру» арқылы осы ашық бетте басқаруды қосыңыз. Құжаттар мен фотоларды сайттағы файл таңдау терезесінен бірнешеуден қосуға болады. «Жою» → «Иә, жою» тек таңдалған файлды серверден жояды және сайттағы тізімді бірден жаңартады.

## Бастапқы баптау

GitHub-та fine-grained personal access token жасаңыз: тек aikerim2019-dotcom/aikerim-portfolio репозиторийін таңдаңыз, Contents үшін Read and write құқығын беріңіз. Кілтті чатқа немесе кодқа қоспаңыз — сайттағы құпия өріске енгізіңіз. Сайт тек репозиторий иесінің аккаунтын қабылдайды.

Кілт тек ашық беттің жадында сақталады. localStorage, sessionStorage, cookie немесе жария кодқа жазылмайды. Бетті жапсаңыз немесе жаңартсаңыз, қайта кіру қажет. Кілт тек api.github.com серверіне Authorization тақырыбы арқылы жіберіледі. Оны GitHub-та қайтарып алуға немесе мерзімін шектеуге болады.

## Бірнеше файл

Бір файл 15 МБ-қа дейін, бір жүктеу 100 МБ-қа дейін. PDF, DOC, DOCX, PPT, PPTX, JPG, PNG, WebP, GIF қолданылады. Атауы бірдей файлдар алмастырылмайды: жаңа файлдың атауына (2), (3) сияқты белгі қосылады. Бір топ файл бір commit арқылы бірге сақталады. Қатарынан жасалған басқа өзгерістер болса, күшпен жазылмайды: тізімді жаңартып, қайталау ұсынылады.

Жаңа файлдар және жою нәтижесі басқарушыға бірден көрсетіледі. Басқа келушілерге GitHub Pages жариялауы аяқталған соң көрінеді. Оқу қоржыны мен қалған карточкалардың файлдары бөлек сақталады.
