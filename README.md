# Айкерим Кусанова — кәсіби портфолио

Портфолио және құжаттар қоры. PDF пен суреттер браузерде ашылады, Word және PowerPoint файлдары жүктеп алынады.

## Құжат қосу

Сайттағы «Құжат қосу» бөлімінен санатты таңдаңыз. GitHub-та өз аккаунтыңызбен кіріп, файлды жүктеңіз, содан кейін «Commit changes» арқылы сақтаңыз. Жариялау аяқталғанда құжат сайтта пайда болады. Файлдың атауы құжаттың атауы ретінде көрсетіледі. Мысалы: «Біліктілікті арттыру сертификаты 2026.pdf».

Санаттар: documents/certificates, awards, materials, articles, students, other.
Құжатты өшіру: «Құжаттарды басқару» → қажетті файл → Delete file → Commit changes.

## Жариялау

GitHub Pages, GitHub Actions. Құжаттар тізімі әр жаңартуда автоматты жиналады. Келушілерге аккаунт қажет емес. Жаңа файл қосу құқығы сайт иесінде.

Build: node scripts/build.mjs
Metadata for curated titles: documents.meta.json
