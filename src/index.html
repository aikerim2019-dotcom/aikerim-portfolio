Басқаруға кіру

Басқару кілтін енгізіңіз. Ол тек осы ашық бетте сақталады. Файл қосу мен жою сайттың өзінде орындалады.

Алғаш рет: басқару кілтін қалай аламын?
  1. GitHub-та жеке басқару кілтін жасаңыз.
  2. Only select repositories таңдаңыз, тек aikerim-portfolio жобасын белгілеңіз.
  3. Repository permissions → Contents → Read and write құқығын беріңіз. Қалған құқықтарды қоспаңыз.
  4. Generate token басып, алынған кілтті осы терезеге енгізіңіз. Кілтті чатқа жібермеңіз.

Бұл бастапқы баптау ғана. Кейін әр файл үшін сыртқы бетке өтудің қажеті жоқ. Бетті жапсаңыз, қайта кіру қажет.
